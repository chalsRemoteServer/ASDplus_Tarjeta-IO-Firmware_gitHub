Este repositorio tiene como único propósito administrar la organización del desarrollo de código de la tarjeta **IO-ASD+**, utilizada en la máquina detectora **ASD+**.

## Contenido del repositorio

Aquí se gestionan y organizan los distintos componentes de software, firmware y documentación relacionados con la tarjeta IO-ASD+, incluyendo:
